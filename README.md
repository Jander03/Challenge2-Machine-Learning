# Challenge 2: Pipeline de Machine Learning - Infecciones Respiratorias Agudas (IRA) en el Perú

## Presentación del Caso
El Perú enfrenta un desafío crítico en materia de salud pública relacionado con las Infecciones Respiratorias Agudas (IRA) y la neumonía en menores de 5 años. A pesar de una disminución reciente, las proyecciones para 2025 indican 824,978 episodios de IRA y un registro histórico reciente de defunciones que exige optimización en la respuesta sanitaria.

## Formulación del Problema
El sistema de salud debe distribuir un inventario finito de recursos (2,226,142 dosis de vacunas contra el neumococo y 8.2 millones contra la influenza) a través de diversas regiones del país, enfrentando vacíos de información sobre factores climáticos y distribución regional de casos. El problema radica en cómo asignar eficientemente estos recursos para minimizar los episodios graves y reducir a cero las defunciones prevenibles.

## Justificación de Inteligencia Artificial y Machine Learning
Abordar este problema mediante Inteligencia Artificial permite transitar de un enfoque reactivo a uno predictivo. 
1. **Modelos de Búsqueda y Razonamiento:** Permiten a un agente inteligente explorar el espacio de estados y asignar vacunas de forma heurística, priorizando regiones con mayor tasa de mortalidad histórica.
2. **Machine Learning (Regresión):** Permite utilizar los datos históricos de defunciones para proyectar tendencias futuras, evaluando si las políticas actuales son suficientes o si requieren ajustes inmediatos. Esto mitiga el impacto de las variables no reportadas mediante el descubrimiento de patrones matemáticos.
